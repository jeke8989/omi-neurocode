# Mnemo

*Помнит ваш день.* Проект NeuroSoft.

Своё приложение и сервер для кулона **Omi Consumer V1** (прошивка 3.0.x, без перепрошивки): запись разговоров, умный агент на кнопке с ответом голосом в наушник, лента задач с интеграциями, дневник жизни и маркетплейс расширений. Подписка и облако Omi не нужны.

```
Кулон Omi ──BLE──► Android-приложение ──WebSocket──► Сервер (VPS)
 (Opus 16 кГц)     • очередь на диске, ничего не теряется      gateway  — приём звука, API, вопросы с кнопки
 кнопка ─────────► • вопрос с кнопки → /ws/ask → ответ голосом  stt      — расшифровка (Whisper через OpenRouter)
                   • чат с агентом, дневник, задачи             agent    — итоги, дневник, задачи → Notion/GitHub
                   • геолокация и фото дня (по желанию)         Postgres — всё хранится у вас
```

## Что умеет

| | |
|---|---|
| 🎙 **Запись** | Звук с кулона идёт на ваш сервер. Нет сети — копится в телефоне (до ~35 ч) и догружается. Каждый пакет подтверждается сервером. |
| 🔘 **Кнопка: 1 нажатие** | Задаёте вопрос голосом и через пару секунд слышите ответ в наушнике. Сигналы «слушаю» и «принял», конец вопроса определяется по паузе. Повторное нажатие означает «я закончил», нажатие во время ответа останавливает его. Если связи нет, вопрос ставится в очередь и ответ придёт в чат. |
| 🔘 **Кнопка: 2 нажатия** | «Запомни это»: последняя минута разговора превращается в запись в памяти, в ответ звучит «Запомнил». |
| ✨ **Агент с уровнями** | *Быстро* — голосом за секунды. *Основательно* — с инструментами. *Глубоко* — составляет план и работает в несколько шагов на сильной модели. Шаги видны в чате: «🔎 Ищу…», «📝 Создаю задачу…». |
| 🧰 **Инструменты агента** | Веб-поиск, задачи, память, поиск по прошлым разговорам, расшифровка последних минут, расширения из маркетплейса. |
| ✅ **Лента задач** | Задачи собираются сами из разговоров, кнопки и агента. Каждая новая задача уходит в подключённые сервисы (Notion, GitHub Issues…). |
| 📔 **Дневник жизни** | Каждый день собирается история: настроение, хайлайты, места по геолокации, фото дня в выбранном ИИ-стиле. Фото отбираются под события, а не все подряд. Каждая часть отключается в настройках. |
| 🧩 **Маркетплейс** | Расширения в виде одного `manifest.json`: декларативные HTTP-инструменты и интеграции задач. Каждое ограничено своим списком доменов. Формат описан в [server/marketplace/README.md](server/marketplace/README.md). |
| 🤖 **Модели** | Один ключ OpenRouter на всё. В приложении для каждой задачи выбирается своя модель, видны живые цены и расход за 30 дней. |

## Установка сервера

На VPS (Ubuntu/Debian, рядом с другими сервисами, например Jarvis: отдельный docker-проект и свой порт) — одна команда:

```bash
curl -fsSL https://raw.githubusercontent.com/jeke8989/omi-neurocode/main/server/install.sh | sudo bash
```

`install.sh` скачивает код (или обновляет уже установленный в той же папке) и запускает `server/deploy.sh`. Тот ставит Docker, создаёт `.env` со случайным паролем БД и ключом доступа, спрашивает ключ OpenRouter, проверяет, что порт свободен, запускает 4 контейнера (`db`, `gateway`, `stt`, `agent`) и в конце печатает **код подключения из 8 цифр** для приложения. Новый код: `docker compose exec gateway python -m neuro.pairing`.

Полезное: `docker compose logs -f --tail 50`, `docker compose up -d --build` (обновление), `docker compose down` (остановка; данные сохраняются).

## Приложение

APK собирается в GitHub Actions при каждом изменении `android/`: вкладка **Actions** → *Android APK* → артефакт, либо **Releases**. Новые версии ставятся поверх старых.

1. Отвяжите кулон в приложении Omi: кулон работает только с одним приложением.
2. Установите APK и откройте Mnemo. Разрешите Bluetooth и уведомления — приложение само найдёт кулон рядом и начнёт запись.
3. Разрешите работу в фоне (кнопка на последнем шаге).

4. На главном экране нажмите «Подключите сервер» и введите код, который напечатала установка сервера. Ключ доступа приходит в ответ и хранится только в телефоне.

Адрес сервера по умолчанию берётся из `neurosoft.properties`; при подключении его можно поменять. Ключ доступа в репозитории и в APK не хранится: репозиторий публичный.

Языки: русский, English, Türkçe, Español — как в системе или по выбору в настройках. Итоги, дневник и голос ассистента переходят на тот же язык.

## Безопасность

- Пароль БД и ключ доступа приложения генерируются на сервере и лежат только в `.env` (не попадает в git). Приложение получает ключ по одноразовому коду: 8 цифр, 30 минут, один раз, не больше 5 ошибок. Ключ, который раньше лежал в репозитории, `deploy.sh` заменяет автоматически.
- Голоса (отпечатки и короткие записи) хранятся только на сервере; в приложении их можно забыть по одному или все сразу.
- Сырой звук записей хранится 3 дня (`KEEP_AUDIO_DAYS`); в приложении: Настройки → Данные → Звук записей. Там же можно выбрать «Удалять после расшифровки»: тогда звук стирается сразу, как только кусок расшифрован. Расшифровки, итоги и дневник остаются.
- Ключ OpenRouter хранится только в `.env` сервера. Если ключ где-то засветился, замените его на openrouter.ai и поставьте лимит расходов.
- Пока сервер доступен по `http://IP:порт`. Следующий шаг — домен и HTTPS (Caddy), после чего http в приложении можно отключить.
- Расширения ходят только на свои домены, а секретные настройки не возвращаются в приложение.
